# 🚨 CrisisLens AI

> Multimodal AI-Powered Disaster Triage, Tactical Command, and Emergency Response System. Built for Hackday 1.0.

## 🌟 Overview
**CrisisLens AI** is an advanced, empathy-driven emergency response and triage dashboard designed to bridge the gap between civilians in crisis and emergency dispatchers. By combining Google Gemini Vision AI, real-time Firebase synchronization, AR mode, acoustic breath detection, and dynamic shelter supply tracking, CrisisLens provides instantaneous, actionable guidance under low-bandwidth conditions.

---

## 🚀 Key Features
- **Gemini Vision AI Triage:** Instantly processes disaster imagery/live camera feeds to compute hazard severity scores and generate actionable emergency steps.
- **Firebase Real-Time Sync:** Synchronizes active incidents and updates seamlessly across multiple command dashboard views.
- **AR Tactical Navigation:** Heads-up display mode with safe corridor routing overlays and heading data.
- **Empathy-Driven Modules:** 
  - Missing Persons AI facial matching across shelter nodes.
  - Faint acoustic breath/heartbeat detector.
  - Pet and livestock rescue flagging.
  - Loved ones voice reassurance notes.
- **Smart Infrastructure:** Dynamic shelter capacity & supply burn-rate predictor (water and food depletion tracking).
- **Multi-Language Support:** Instant localization for English, Spanish, Hindi, and Tamil.
- **Twilio SMS SOS:** Automated mobile alert dispatching.

---

## 🛠️ Tech Stack
- **Frontend & UI:** Next.js (App Router), React, Tailwind CSS, TypeScript, Lucide Icons
- **Backend & State:** Firebase Realtime Database
- **AI & APIs:** Google Gemini Vision AI API, Twilio SMS API, Web Speech API
